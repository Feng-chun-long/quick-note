核心功能

简单到没什么好介绍的

📝

点图标直接写

工具栏图标一点就开，弹窗里直接打字，没有中间步骤。

🔗

自动带网页信息

保存时自动记录当前页面标题和完整网址，回头点链接直接跳回去。

💾

本地持久化

用浏览器内置存储，关掉浏览器还在，重启电脑还在。没有后端不上传。

🗑️

随手删

每条笔记一个删除按钮，点确认就删干净，没有回收站。

⌨️

快捷键保存

Ctrl + Enter / ⌘ + Enter 快速存，不用伸手去点鼠标。

🔒

零网络请求

没有 API Key、没有服务器、没有登录，插件本身不会访问任何网址。

安装步骤

3 分钟搞定

  1. 1

    下载并解压

    下载 ZIP → 解压到固定位置（比如 D:\extensions\quick-note\），不要放临时文件夹。

    ⬇️ 下载 quick-note.zip
  2. 2

    打开扩展管理

    Chrome 地址栏输入 chrome://extensions；Edge 输入 edge://extensions。右上角打开「开发者模式」。

  3. 3

    加载扩展

    点「加载已解压的扩展程序」，选择 ZIP 里的 extension/ 子文件夹（里面有 manifest.json）。

使用方法

四个动作，记一条笔记

①

打开任何网页——新闻、论文、知乎、B站视频都行。

②

点浏览器工具栏上的「快捷笔记」图标。

③

弹窗里打字，Ctrl+Enter 或点「保存」。

④

完事。关掉浏览器再打开，笔记还在。

常见问题

笔记存在哪了？会不会丢？

存在浏览器本地存储（chrome.storage.local），关掉浏览器、重启电脑都不会丢。但卸载扩展时会一起清掉，也不会跨浏览器同步（Chrome 和 Edge 存储是独立的）。

为什么点图标没反应？

大概率是加载时选了错的文件夹——必须选 extension/ 子目录（里面有 manifest.json），不是整个项目根目录。重载后再试。

笔记能导出吗？

目前版本没做导出功能。要备份可以手动复制重要内容。后续版本会加导出 JSON/Markdown。

支持哪些浏览器？

任何 Chromium 内核的浏览器：Chrome、Edge、360、QQ 浏览器、Vivaldi 等。Firefox 不支持（用的是 WebExtensions 不同 API）。

为什么 about:blank 页面显示「未检测到页面」？

新标签页内部地址 chrome:// / edge:// / about:blank 这些页面 tab.query 拿不到 title 和 url，所以显示这个，属于正常现象。
